# Практическая работа 16. Руководство оператора учебного сервиса заявок

Репозиторий содержит руководство для обычного сотрудника, который впервые пользуется учебным сервисом заявок версии 1.5.0, и материалы его проверки.

## Что сдаётся

- `operator_guide.md` — руководство оператора и техника по пяти сценариям.
- `role_matrix.md` — матрица двух целевых ролей: оператор и техник.
- `usability_test.md` — протокол аналитического испытания по модели интерфейса.
- `change_log.md` — история исправлений после проверки.
- `checkpoint_1.md` — промежуточный результат первой пары.
- `ai_review.md` — запрос к ИИ для проверки ясности и одна содержательная правка.
- `data/` — исходные материалы задания без изменений.

## Режим проверки

Стенд не предоставлялся. Испытание выполнено как **аналитическое испытание по модели интерфейса** по `data/operator_observations.md`. Фактическое поведение приложения не подтверждалось. Отзыв партнёра не выдумывался: зафиксировано ограничение «один автор».

## Границы руководства

Руководство не описывает CI/CD, миграции, серверную базу, установку, административные действия и работу менеджера. Для оператора и техника описаны только действия, которые можно выполнить по наблюдениям интерфейса версии 1.5.0. Если нужного действия нет в описании, руководство требует остановиться и обратиться в поддержку, а не угадывать элемент.
