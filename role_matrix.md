# Матрица ролей

Версия: 1.0  
Источник: `data/service_spec.md`, `data/operator_observations.md`.

## Целевые роли

| Роль | Доступные действия | Ограничения | Что не входит в руководство |
|---|---|---|---|
| `operator_a`, `operator_b` — оператор | Создают заявки; читают собственные заявки; редактируют собственные открытые заявки; прикладывают от 0 до 3 файлов PDF/PNG; проверяют сохранение по номеру и повторному открытию. | Видят только свои заявки. Не видят чужие карточки. Не назначают исполнителя. Не выполняют административные действия. Не обходят ограничения доступа. | Назначение исполнителя, просмотр всех заявок, серверные настройки. |
| `technician_a` — техник | Читает только назначенные ему заявки; переводит назначенную заявку из `open` в `in_progress`; затем переводит в `resolved` с непустым комментарием. | Видит только назначенные заявки. Удаление не разрешено. Не может завершить заявку без непустого комментария. Не создаёт заявки по спецификации. | Назначение исполнителя, удаление заявок, административный доступ. |

## Ключевые ограничения по спецификации

- Доступ ограничивается сервером; отсутствие кнопки само по себе не является проверкой полномочий.
- Оператор не должен пытаться открыть чужую заявку или обойти экран ошибки доступа.
- Техник не должен искать обходной путь для удаления: удаление не разрешено.
- Завершение заявки требует непустого комментария исполнителя.
- При отказе валидации введённый текст остаётся в форме.
- После сетевого тайм-аута сначала проверяется список заявок, потому что операция могла сохраниться.

## Роли вне руководства

`manager_a` и неавторизованный пользователь описаны в спецификации, но в руководстве оператора не инструктируются. Действия менеджера и администратора вынесены за границы руководства.

## Словарь (5 терминов интерфейса)

| Термин | Определение, помогающее действию |
|---|---|
| Заявка | Запись с темой, описанием, статусом и вложениями; создаётся на «Новая заявка» |
| Номер | Идентификатор записи (например, `LAB-104`) для поиска и повторного открытия |
| Статус | Состояние: `open`, `in_progress`, `resolved` |
| Вложение | Файл PDF/PNG, не более 3, каждый ≤ 5 000 000 байт |
| Исполнитель | Сотрудник, которому назначена заявка (например, `technician_a`) |
